> This is the permanent architectural vision for Xeroww. Every future design, code review, feature, refactor, and research decision should move the project toward this direction. This is not a hackathon dashboard, stock prediction app, or paper trading clone. It is an institutional-grade Distributed Explainable Financial Intelligence Platform built by a Computer Science undergraduate to demonstrate elite systems engineering, distributed computing, explainable AI, and software architecture.

# 0. The Philosophy

## What Xeroww is

Xeroww is a financial intelligence workstation that explains markets through deterministic computation rather than prediction.

The platform should answer questions like:

* Why is this market bullish?

* Which evidence supports this conclusion?

* Which rules fired?

* What changed between two candles?

* How would this decision have looked in real time?

* Which subsystem generated this insight?

It is a reasoning engine, not a guessing engine.

## What Xeroww is NOT

Never let the project become:

* A TradingView clone

* A Zerodha clone

* A Robinhood clone

* A paper trading simulator

* An AI stock predictor

* A dashboard with 500 indicators

The differentiator is systems + explainability, not visual indicators.

## Current implemented state: V0.11

The current product has moved beyond a market dashboard into three connected decision-support workflows:

* The Decision Workbench captures immutable plans, evidence, risk, portfolio context, and append-only amendments.

* The Replay and Behaviour Lab persists server-owned historical sessions, blocks future-data exposure, requires a decision before progression, records executions and reflections, and scores process separately from outcome.

* Portfolio Intelligence stores point-in-time valuation snapshots and explains observed return, drawdown, attribution, covariance, correlation, beta, risk contribution, concentration, and pre-decision portfolio impact.

The default product surfaces stay compact. They show one status, a small KPI set, no more than three primary warnings, and one dominant chart or table. Formula detail, provenance, event history, and longer explanations remain available through progressive disclosure.

Replay is a deliberate-practice environment, not a paper trading game. Portfolio warnings are advisory, not recommendations. Both modules preserve the core rule that calculations must be deterministic, versioned, testable, and inspectable.

# 14. Engineering Principles

## Every feature must satisfy:

* Deterministic

* Explainable

* Testable

* Replay compatible

* Event-driven

* Typed

* Documented

If a feature violates one of these, redesign it.

## Code Quality

* 90%+ unit coverage for critical services

* Pure functions wherever possible

* DTO-first APIs

* No business logic inside routes

* Service composition through orchestrators

* Feature folders over utility dumping

# 15. Final Identity Statement

> Xeroww is a distributed, event-driven, explainable quantitative market intelligence platform that transforms raw financial time-series data into deterministic, human-understandable reasoning through modern software architecture, big data infrastructure, and classical explainable AI.
