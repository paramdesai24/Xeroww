# Portfolio Intelligence

Portfolio Intelligence adds a compact portfolio intelligence workspace alongside the replay and behaviour lab.

## Included

- Snapshot valuation, return tracking, attribution, and portfolio risk analytics.
- Pre-decision portfolio impact checks that remain advisory and explainable.
- Benchmark-aware market data retrieval for comparison calculations.
- Authenticated portfolio intelligence endpoints and a compact dashboard experience.
- Formula documentation and calculation-focused automated coverage.

## Operating principle

Portfolio outputs describe observed portfolio state and calculated risk. They do not place trades or provide execution advice.
